Twitch Chat Integration Template

This template provides a basic framework for connecting your web application to Twitch chat. It handles connecting to a channel, displaying chat messages, and routing commands to your application logic.

Instructions

  1. Enter a Twitch channel name below (e.g., gamesdonequick).
  2. Click Connect to start receiving messages.
  3. Open your browser's developer console (F12) to see logged commands.
  4. Edit main.js to define your own commands and application logic.
